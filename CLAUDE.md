Personal portfolio. Tagline: **"Curiosity builds what comes next."** / **"A curiosidade constrói o que vem a seguir."** (per locale, `messages → hero.tagline`).
Edited like an independent one-author magazine: each section opens with a typographic thesis, shows real evidence, closes with a question.

## Hard rule — no fabrication
Never invent achievements, metrics, test results, clients, testimonials, dates, roles or contact details. The design's copy is mostly placeholder. A fact without a source stays `undefined` and the UI omits it; data copied from the design carries `confirmed: false`. Never present unshipped work as shipped.

## Stack
- Next.js 16 App Router, React 19, TypeScript strict (`noUncheckedIndexedAccess`), `src/`, `@/*` alias.
- **Static export** (`output: "export"`) → Cloudflare Workers static assets (`wrangler.jsonc`, `./out`). No middleware, Next route handlers that need a runtime, server actions, ISR or image optimisation. The one runtime piece is the cat's Worker (below), outside Next. `/` → `/pt` via `public/_redirects` (+ meta-refresh fallback in `src/app/page.tsx`).
- Tailwind CSS v4, CSS-first: all tokens in `src/app/globals.css` `@theme`. No `tailwind.config`.
- GSAP + ScrollTrigger + `@gsap/react` only (no second motion library). Import from `@/lib/gsap`, never from `gsap` directly.
- next-intl 4: locales `pt` (default) and `en`, `localePrefix: "always"`. Every page/layout under `[locale]` calls `hasLocale` + `setRequestLocale` and exports `generateStaticParams`. UI strings in `messages/{pt,en}.json` (pt is the type source); facts in `src/content/*` with `Localized<T>` fields. **No `next-intl/plugin`:** `next.config.ts` sets the `next-intl/config` alias itself (Turbopack + webpack), because the plugin loads `@swc/core` at import and its native loader fails in Cloudflare's build image (ERR_SWC_NATIVE_CACHE, 2026-11-13).
- Fonts self-hosted via `next/font/local` (`src/fonts/*.woff2`): **Satoshi** variable (wght 300–900, display, `font-display`; titles 700, numerals 900), **IBM Plex Sans** 400/500/600 (body, `font-sans`, OFL; no italic face: nothing is set in italic and next/font preloads every face of a family, so re-add `IBMPlexSans-Italic.woff2` only when italic text exists), **Instrument Serif** italic (`font-serif`, OFL) is declared with `preload: false` and used nowhere, so it is never downloaded (Iury, 2026-11-11: the curved face did not work); annotations (`text-note`: dates, status, captions, field names) are Satoshi Medium in a muted tone. The hero statement is Satoshi. No monospace anywhere.
- **Satoshi licence (ITF Free Font License):** self-hosting on this site and making wordmarks are allowed; modifying the font (subsetting, conversion) and distributing it, including through this **public** repo, are not. So the Satoshi files are never committed (`.gitignore`): `scripts/fonts.mjs` fetches the official package before every build (`npm prebuild`; `--lettering` also fetches the TTF for the lettering script). Never commit, subset or convert them.

Type scale (`text-*`, fluid 375→1440): `display-xxl` 208→64, `display-xl` 120→48, `headline-l` 64→36, `headline-m` 40→28, `title` 24→20, `numeral` 96→56 (Satoshi); `lead` 22→19, `body` 17→16 /1.62 max 68ch, `ui` 15, `caption` 13 (Plex); `text-note` 16 (Satoshi 500, muted). The display face never below 14px. On dark, titles under 40px go one weight up. Display breaks are hand-set per breakpoint; `text-wrap: balance` is the safety net.

**Global scale (Iury, 2026-11-13):** on `(min-width: 64rem) and (hover: hover) and (pointer: fine)` the root font-size is 75%, so the site at 100% zoom reads as it did at 75% (everything in rem follows; media queries do not). **Phones and tablets are zoomed out too (Iury, 2026-11-16):** phones 87.5% (14px), tablets and windows from 48rem 81.25% (13px), fine-pointer desktops 75%. Touch targets never shrink: `--spacing-11` / `--spacing-12` (so `min-h-11`, `size-11`, `min-h-12`, `pr-12`…) read `--tap-11/12`, which is `max(2.75rem,44px)` / `max(3rem,48px)` on a coarse pointer and plain rem with a mouse; anything else sized for touch writes its own px floor (the hero cat `w-[max(var(--spacing-11),7.5cqw)]`, the dock disc `pointer-coarse:size-[max(3.5rem,56px)]`). Reading text keeps floors: `text-body` ≥14px, `ui` ≥13px, `caption` ≥12px, `label` ≥12px, `text-note` ≥13px, and arbitrary small sizes are written `text-[max(…rem,…px)]`. Size new things in rem so they scale; px stays fixed. **Large monitors (2026-11-16):** from 90rem (1440px) with a mouse the root grows with the window, `clamp(75%, 0.4464vw + 34.82%, 110%)` (12px at 1440, ~14px at 1920, ~17px at 2560), so wide screens show the same composition larger, never a 1080px column; 1440 is unchanged.

**Responsive variants (globals.css, 2026-11-16):** `short` = `max-height: 34rem` (phones held sideways, small windows: the hero stops being a full-height poster, its column is `min(100%,34rem)`, the assistant panel takes the height); `bare` = md + mouse + taller than 34rem (the only place the nav wordmark is bare text; touch and short screens give it the glass pill once past the hero); Tailwind's `pointer-coarse:` lifts touch targets to 44px where the desktop scale made them smaller (language pill, footer links). Breakpoints follow the content: under 380px the wordmark reads "Iury" (the link's label keeps the full name); under 480px the case nav's back pill is an arrow (labelled); md (768) is the tablet composition (Profile's education and skills side by side, each career step in two columns on the vertical line); lg (1024) the desktop one. Test with the scratchpad `resp/audit.cjs` (13 widths, portrait/landscape, touch/mouse: horizontal scroll, clipped/tiny text, targets < 44px) and `resp/orient.cjs` (rotation, resize churn, 200% zoom).

Layout: `page-grid` utility = 12 cols (gutter 24, margin up to 56, max 1440) / 4 cols mobile (gutter 16, margin 20). Asymmetric: text 7 cols, air 5 — never centred by default. Spacing base 8; sections 160 desktop / 96 mobile. Radius 0, no rules or dividers on content, no shadows, no decorative gradients, no rounded cards. Pill + glass only for floating controls (nav, assistant); both carry a 1px luminous edge (border paper/20–24 + inset top highlight). Project status is said in words (`StatusMark` renders the label in `text-note`).

Accent on light: use the `highlight` utility (sized gradient that stays inside tight display leading), never `bg-signal` on inline text.

Surfaces: Hero dark → Profile (`#about`) light → Projects light (with Approach inside it, `#approach`) → Contact dark. (The Lab section was removed, Iury 2026-11-13.) Every home section opens with `pt-(--section-space)`. Case study: light editorial. Mark light sections `data-surface="light"` (switches focus ring to ink). The nav reads the surface from geometry: the innermost `[data-surface]` box spanning the line 44px from the top (an `elementsFromPoint` hit-test was the costliest call while scrolling; a clipped layer would need it back); `data-nav-as` on a surface overrides the active item; dispatch `SURFACE_EVENT` (`components/layout/surface.ts`) when a surface changes without scrolling.

## Graphic system (R7: no markers)
Iury, 2026-11-11: no marking patterns (codes like T.01 / E.02 / P.01, numbered labels, rulers, hairline rules, square markers, grids, crop marks, crosshairs). Structure comes from type, scale, space and imagery.
- **Voices:** Satoshi names (titles, projects, roles, actions) and, in Medium + a muted tone, annotates (`text-note`: a date, a status, a caption, a field name, "imagem em breve"). Plex explains (reading text). No monospace, no italic serif, no tracked uppercase eyebrows.
- **Order without numbers:** sequences read through placement and scale (the Approach verbs step down; the career roles climb and grow). If a list is a sequence, let the layout say it.
- **Separation by space, not lines.** Lists are spaced paragraphs; a field name in serif above its value replaces a label + rule.
- **Links and actions:** Satoshi bold with an underline (the one line allowed: a typographic affordance), or the paper/ink block button. Nav active item: full opacity, others 65%.
- **Pictures, not wireframes:** a project without a cover gets a typographic poster (its own name in Satoshi Black, cropped by the frame, `ProjectImage`); case-study slots without media show a tone and one serif line.
- **Allowed accents:** the lime `highlight` (max 2 per viewport), grain + soft light on dark surfaces, the cat, the lettered name.
- **Interaction feedback:** hover/focus quiets siblings (opacity) and unrolls details in place (clip-path), never a floating popover. Panels open under what opened them with a clip-path reveal (`DUR.slow`).

## Motion
- Durations: fast 160 (hover/focus), base 320 (states/panels), slow 640 (entrances/reveal). One easing: `--ease-out-soft` `cubic-bezier(0.2,0.7,0.1,1)`.
- Animate only transform, opacity, clip-path, mask. Never layout properties.
- Use `useGSAP` (scoped context, auto-revert) and `gsap.matchMedia()` with `MQ` from `@/lib/gsap`. Kill ScrollTriggers, listeners and observers on unmount.
- Content is present in the server HTML. Entrance start states live in CSS under `.js` (class added by an inline script in `[locale]/layout.tsx`) inside `prefers-reduced-motion: no-preference`, with a 3s CSS failsafe (HeroMotion sets `animation: none` on the glyphs once its entrance ends: the forwards-filled failsafe kept them as composited layers for good); GSAP then animates with `fromTo` (zero any `y` GSAP would parse from the CSS) and no `clearProps`.
- `prefers-reduced-motion`: no jumps, lerps or breathing; instant swaps or hard cuts. The global reset uses `transition: none` — never a tiny duration (it makes computed styles lag a frame).
- Scroll stages: the element with the tall height must be the sticky element's direct parent.
- Effects always use a block body: `useEffect(() => { … })`. Never return an expression — e.g. `scrollIntoView()` now returns a Promise in Chromium, which React then tries to call as the cleanup and crashes.
- No always-on rAF loops: loops start on interaction and stop on idle or `visibilitychange`. The one exception is GSAP's own ticker while a tween runs.
- No permanent `will-change` (it kept the deck cards as layers for good; GSAP's `force3D: "auto"` promotes only during a tween). Scroll-frame code reads geometry before it writes, never reads `scrollHeight` or hit-tests per frame (cache and refresh on resize), and touches an attribute only when its value changes. Before and after any performance change, measure (scratchpad scripts in the 2026-11-16 audit, NOTES.md); keep a change only when the numbers move.

## The AI (Iury, 2026-11-16)
- `worker/index.ts` is a Cloudflare Worker that only answers `/api/*` (`assets.run_worker_first`); everything else is served from `./out` without running it. `POST /api/chat` calls Gemini (`generateContent`, `x-goog-api-key`) with the system prompt + `knowledge/*.md`. Free tier only: no billing, so abuse cannot cost money; past the quota Google answers 429 and the cat falls back to scripted answers.
- **Grounding, not training.** The model answers only from `knowledge/*.md` (Iury's words; one topic per file). `scripts/knowledge.mjs` (runs in `prebuild`, or `npm run knowledge`) writes `worker/knowledge.generated.ts` (generated, committed, never hand-edit). Lines with `[PREENCHER` and HTML comments are left out. **`knowledge/` is public and goes to Google on every question: only write what may be read by anyone.** Same no-fabrication rule as the site.
- Secret `GEMINI_API_KEY` lives in the Worker (dashboard → Settings → Variables and Secrets; it cannot be added to an assets-only Worker, so the script had to ship first). Never in the repo or the browser. `GEMINI_MODEL` is a comma-separated list in `wrangler.jsonc` (order of preference; the Worker moves on at 404/429 because Google retires models: gemini-2.5-flash answered 404 on 2026-11-16).
- Free-tier data may be used by Google to improve its products (pricing page): the panel shows `assistant.ui.privacy` in both locales. Keep it.
- **Answer cache:** the first question of a conversation (no history) is cached in the KV `CHAT_CACHE` for 3 days, keyed by the normalised question + a hash of the system prompt + the page, so repeats cost no Gemini quota and editing `knowledge/` invalidates old answers. A hit skips the limiter. KV, not the Cache API: that one does nothing on `workers.dev`. Namespace `portfolio-chat-cache` (id in `wrangler.jsonc`).
- Limits in the Worker: same-origin only, ≤11 turns, user text ≤300 chars, `maxOutputTokens` 1100, temperature 0.4, 7 s per model attempt, a best-effort per-isolate limiter. The client sends the last 10 turns and the case slug.
- **Output guard** (`worker/guard.ts`, a second layer behind the prompt): a reply with an e-mail, link or @handle that is not in the knowledge text, a leak marker, an invented family anecdote or personality trait or a non-existent site section (`INVENTED` regex: "lá em casa a gente sempre…", "reservado", "seção de vida pessoal"; the family voice made the model do this once), or more than 2000 chars is dropped (not shown, not cached) and the next model is tried; if none is clean the client falls back to scripted answers. Keep the contacts in `knowledge/` accurate: the guard allows only those. Personal life is published on purpose (Iury, 2026-11-16: `knowledge/pessoal.md`: month/year of birth, region, faith and church, AWAKE, hobbies, weekends, girlfriend without a name, wedding plan for 2027). Also published (Iury, 2026-11-16): full name (Iury dos Santos Umbelino), a younger sister (no name), the cats (Tisco now; Pühakud, 2019, gone in 2026; the name is Estonian for "saints"). Left out on purpose: exact birth date, her name, the sister's name, address, phone, prices and third-party clients, internal Giassi details, project ids. The prompt gets today's date so the age is computed, not stored.
- **Pointing to the site.** The model may end a reply with `[[ir:destino]]`; `extractGo` (`worker/guard.ts`) strips it and accepts only `about|projects|approach|contact` or a project slug (`PROJECT_SLUGS`, generated from `projects.ts` by `scripts/knowledge.mjs`, so new projects work without edits). The reply carries `go`; the panel shows a Satoshi-bold underlined link under the cat's answer (`assistant.go.*` labels, built in `assistantProps` from the projects that have a page). `destinationFits` (guard.ts) keeps a section link only when the VISITOR's question is about that section (topic regexes; a project page needs its name in the question or reply), and `isPersonalTopic` removes `go` whenever the question or reply is about personal life (no page exists for it; Iury, 2026-11-16: a girlfriend answer once linked to Profile). The cat's voice is a family member's (warm, close, proud of Iury; "lá em casa"; no invented scenes). It is conversational: 3 to 6 sentences, connects facts without adding any, ends with a follow-up question or suggestion. It never navigates by itself (a page change would lose the answer); on the home a section link closes the panel and scrolls, elsewhere it is a normal link. The cache stores `{reply, go}` (key prefix v2).
- **Resilience (Google errors).** Whole request deadline 12 s (the browser gives up at 14 s), 7 s per attempt, never an attempt with under 1.5 s left. Any non-OK status (404 retired, 429 quota, 5xx overloaded, 400/403), a timeout, an empty reply (a thinking model that spent its tokens), a safety block or a guard rejection moves on to the next model. A model that fails is benched per isolate (404 10 min, 429 1 min, others 45 s) and tried last, so visitors do not each pay a timeout. If every attempt was a 429 the Worker answers `quota`. The panel tells the visitor: `rate_limited` ("muitas perguntas, espere um minuto"), `quota` ("muita conversa agora"), anything else falls back to chip keywords, then `fallback`.
- **Visitor limits:** 300 chars per question (also `maxLength` on the field), last 10 turns of context, 8 questions per minute per IP per isolate (best effort), replies up to 2000 chars, first-question answers cached 3 days. Google's free quota per model is the real ceiling (see AI Studio); it is shared by all visitors.
